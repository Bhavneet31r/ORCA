# ORCA — Ocean & Coastal Assistant

ORCA is an educational web prototype for exploring ocean science and coastal information. It combines a Streamlit interface, rule-based query and location parsing, optional Gemini prompt experiments, and marine data lookups. The Flask app and API remain available as an alternate entry point.

> **Important:** ORCA is not an official marine safety, navigation, weather-warning, or fishing service. Its configured boundaries and condition thresholds are illustrative. Always follow official advisories.

## Features

- Ask curated general ocean-science questions.
- Select a supported coastal location or provide coordinates for local queries.
- View forecast summaries and potential fishing-zone estimates when external data are available.
- Review approximate distances to configured coastal boundaries.
- Compare zero-shot and few-shot prompts in the Prompt Lab.
- Inspect prompt iterations and example test inputs.
- Show unavailable-data messages rather than substituting synthetic observations.

## Gemini integration

The Prompt Lab uses **Gemini 3.5 Flash-Lite** when `GEMINI_API_KEY` or `GOOGLE_API_KEY` is configured in the server environment or Streamlit secrets. Without a key, the lab reports that Gemini is not configured. Never commit API keys, passwords, or other credentials. `.env` files are ignored by Git. If a key has been exposed, revoke it and create a replacement.

To enable live Gemini responses locally, stop the running app and set your own key in the same PowerShell window before starting Streamlit:

```powershell
$env:GEMINI_API_KEY = "your-key-here"
.\.venv\bin\python.exe -m streamlit run streamlit_app.py
```

Replace the placeholder with a key from Google AI Studio. Keep the key private; do not paste it into the browser or commit it to the project. Without a key, the local app still runs, but Prompt Lab generation displays a not-configured message. Streamlit Community Cloud reads `GEMINI_API_KEY` (or `GOOGLE_API_KEY`) directly from **Settings > Secrets**.

## Data sources and limitations

- Weather and marine forecast summaries use the Open-Meteo services.
- Sea-surface temperature and chlorophyll observations use NOAA CoastWatch ERDDAP when available.
- General ocean-science answers come from a small, curated local knowledge set; they are not generated by Gemini.
- Prompt Lab generation uses Gemini only when configured.
- The potential fishing-zone output is a simple estimate, not a validated fishing recommendation.
- Configured geofences are approximate reference areas, not official boundary data.
- External services can be unavailable or return incomplete data. Outputs should not be used for real-world safety decisions.

## Run locally with Streamlit (Windows PowerShell)

From the ORCA project folder, start the Streamlit app with its project environment:

```powershell
.\.venv\bin\python.exe -m streamlit run streamlit_app.py
```

Open <http://localhost:8501> in your browser. Leave the terminal open while using the app, and press `Ctrl+C` to stop it. If your virtual environment uses the standard Windows `Scripts` directory instead of `bin`, replace `.venv\bin\python.exe` with `.venv\Scripts\python.exe`.

The original Flask interface and API can still be started with `.\.venv\bin\python.exe main.py` at <http://127.0.0.1:5000>.

## Deploy to Streamlit Community Cloud

1. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/) with GitHub.
2. Create an app using repository `Bhavneet31r/ORCA`, branch `main`, and main file path `streamlit_app.py`.
3. Deploy the app. Community Cloud installs the packages listed in `requirements.txt` and provides a `*.streamlit.app` URL.
4. To enable Gemini, add `GEMINI_API_KEY = "your-key"` in the app's **Settings > Secrets**. Never commit the key to GitHub.

## Run tests

```powershell
.\.venv\bin\python.exe -m pytest -q
```

The tests use controlled fixtures for external data. Passing tests checks application behavior; it does not validate scientific accuracy or real-world safety.

## Project structure

- `streamlit_app.py` — Streamlit interface
- `main.py` — shared analysis logic, Flask application, and API routes
- `intent.py`, `language.py` — query, intent, location, and language handling
- `data_sources.py` — weather and satellite data providers
- `geo_utils.py`, `config.py` — geographic calculations and demonstration configuration
- `ocean_knowledge.py` — curated ocean-science answers
- `prompt_engineering.py` — prompt versions, prompt construction, and optional Gemini integration
- `templates/`, `static/` — web interface
- `tests/` — automated tests
